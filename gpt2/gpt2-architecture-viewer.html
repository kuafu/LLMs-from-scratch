端到端前向传播流 (Forward Pipeline)

1 Token 序列输入 (Input Text & BPE)

文本字符串（如 "Hello, I am"）经 tiktoken BPE 编码为离散 ID 序列：[15496, 11, 314, 716]。

形状: (B, T) = (1, 4)
2 双嵌入相加与 Dropout (Token & Position)

词嵌入矩阵 tok_emb(50257, 768) 与绝对位置嵌入矩阵 pos_emb(1024, 768) 逐元素相加。

形状: (B, T, 768)
tok_embeds = tok_emb(in_idx) # (1, 4, 768)
pos_embeds = pos_emb(0..T-1) # (4, 768)
x = drop_emb(tok_embeds + pos_embeds)
× 12 层堆叠 TransformerBlock 骨干序列
形状: (B, T, 768) 恒定

张量依次流经 12 个完全独立的 Transformer 核心块，每个核心块内部包含 Pre-LN 自注意力分支与 Pre-LN 前馈分支，双重残差直连防止深层梯度消失。

4 最终层归一化 (final_norm)

对第 12 层输出做最终层统计平稳处理：LayerNorm(768)。

形状: (B, T, 768)
5 语言模型分类头 (out_head)

通过无偏置线性层 Linear(768, 50257, bias=False) 映射到全词表未归一化概率（Logits）。

形状: (B, T, 50257)

💡 为什么采用 Pre-LayerNorm?

初代 Transformer (Vaswani et al., 2017) 采用 Post-LN（在残差相加后才做 LayerNorm），在深层网络中梯度极易在反向传播时衰减，必须依赖学习率热身 (Warmup)。

GPT-2 改进为 Pre-LayerNorm：归一化在自注意力与前馈子层之前进行，残差通道（Residual Highway）直接无阻碍连通，极大增强了训练稳定性。

TransformerBlock: Pre-LN 与双残差高速通道 (Residual Highway)

每个 Block 接受形状为 (B, T, 768) 的张量输入，原样输出形状相同的张量。

子层 1：规范化多头因果注意力 (B, T, 768)
1. norm1 (LayerNorm)

对输入 x 沿最后一个特征维度做均值方差标准化，平稳特征分布。

2. att (MultiHeadAttention)

12 个独立注意力头并行捕获多粒度上下文关联，因果掩码遮蔽未来。

3. drop_shortcut (Dropout)

丢弃概率 0.1，训练阶段抑制过拟合。

➔ x = x + shortcut (第一次残差求和)
子层 2：规范化两层前馈网络 (B, T, 768)
1. norm2 (LayerNorm)

为前馈分支独立执行层归一化。

2. ff (FeedForward: 768 ➔ 3072 ➔ 768)

线性升维 4 倍后经平滑的 GELU 非线性激活，再降维投影回 768 维。

3. drop_shortcut (Dropout)

丢弃概率 0.1。

➔ x = x + shortcut (第二次残差求和)

MultiHeadAttention: 多头因果自注意力的四步流水线

将单个 768 维特征向量切分成 12 个 64 维头，在每个子空间内独立做 Scaled Dot-Product 注意力并施加因果掩码。

Step 1: Q/K/V 线性映射
queries = W_query(x)
keys = W_key(x)
values = W_value(x)
形状: (B, T, 768)
Step 2: 拆解多头并转置
view(B, T, 12, 64)
transpose(1, 2)
➔ (B, 12, T, 64)
Step 3: 掩码与 Softmax
scores = Q @ K.T / √64
scores.masked_fill(-inf)
weights = softmax(scores)
Step 4: 汇聚并映射输出
context = weights @ V
拼合为 (B, T, 768)
out_proj(context)

自回归生成循环 (`generate_text_simple`)

展示每次循环如何从当前提示词自增一个 Token，直到达到预定长度。

1. 滑动窗口截断

idx_cond = idx[:, -context_size:]
如果累积序列超过 1024 上限，只保留末尾 1024 个 Token 作为输入。

2. 全模型前向计算

with torch.no_grad():
logits = model(idx_cond)
关闭梯度计算，输出全序列每个位置对 50,257 词表的 Logits。

3. 抓取末尾并贪婪采样

logits = logits[:, -1, :]
idx_next = torch.argmax(logits, dim=-1, keepdim=True)
取最高概率对应候选词。

4. 拼回输入序列

idx = torch.cat((idx, idx_next), dim=1)
序列长度由 T 变为 T+1，开启下一轮迭代。

现代化大模型演进建议 (对标 Llama / Qwen)

1. KV Cache (键值缓存加速生成)

将自回归生成的平方级复杂度 O(N²) 降低为线性复杂度 O(N)，仅对最新 Token 计算注意力。

2. RoPE 旋转位置编码

取代可学习的绝对位置嵌入，赋能模型强大的相对距离感知与长上下文外推能力。

3. RMSNorm 替代 LayerNorm

免除均值中心化统计计算，仅使用均方根缩放，计算速度更快、数值更平稳。

4. SwiGLU 门控前馈网络

在相同参数量预算下显著增强非线性表征与泛化能力。

5. FlashAttention / PyTorch SDPA

硬件感知的高效注意力核函数，避免显存反复读写 T×T 注意力大矩阵。
