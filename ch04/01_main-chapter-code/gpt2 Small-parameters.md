# GPT-2 Small 参数详细说明

本文基于 [gpt.py](gpt.py) 中的 `GPT_CONFIG_124M`,说明 GPT-2 (124M) 的各配置参数、张量形状与参数量计算。

## 1. 配置参数

```python
GPT_CONFIG_124M = {
    "vocab_size": 50257,     # 词表大小
    "context_length": 1024,  # 上下文长度
    "emb_dim": 768,          # 嵌入维度
    "n_heads": 12,           # 注意力头数
    "n_layers": 12,          # Transformer 块数
    "drop_rate": 0.1,        # Dropout 比率
    "qkv_bias": False        # Q/K/V 线性层是否带偏置
}
```

| 参数             | 值    | 含义                                                           | 影响                                                              |
| ---------------- | ----- | -------------------------------------------------------------- | ----------------------------------------------------------------- |
| `vocab_size`     | 50257 | BPE 词表大小(50000 次合并 + 256 字节 + 1 个 `<\|endoftext\|>`) | 决定词嵌入矩阵与输出层的行/列数,是参数量最大的两项来源            |
| `context_length` | 1024  | 模型一次最多处理的 token 数                                    | 决定位置嵌入矩阵大小与因果掩码尺寸;注意力计算量随其平方增长       |
| `emb_dim`        | 768   | 每个 token 的向量维度(即 d_model)                              | 几乎所有权重矩阵的尺寸都与之相关                                  |
| `n_heads`        | 12    | 多头注意力的头数                                               | 要求 `emb_dim % n_heads == 0`;每头维度 `head_dim = 768 / 12 = 64` |
| `n_layers`       | 12    | 堆叠的 Transformer 块数                                        | 参数量与计算量近似线性增长                                        |
| `drop_rate`      | 0.1   | 嵌入层、注意力权重、残差分支的 Dropout 概率                    | 仅训练时生效,不增加参数;预训练大模型常设为 0                      |
| `qkv_bias`       | False | `W_query/W_key/W_value` 是否使用偏置                           | 现代 LLM 通常为 False;**加载 OpenAI 官方权重时需设为 True**       |

派生量:

- 前馈层隐藏维度 `4 * emb_dim = 3072`
- 每头维度 `head_dim = emb_dim / n_heads = 64`

## 2. 模块结构与张量形状

设 batch 为 `B`,序列长度为 `T`(`T <= 1024`)。

| 步骤 | 模块                                | 输入形状      | 输出形状        |
| ---- | ----------------------------------- | ------------- | --------------- |
| 1    | 词嵌入 `tok_emb`                    | `(B, T)`      | `(B, T, 768)`   |
| 2    | 位置嵌入 `pos_emb`(绝对位置,可学习) | `(T,)`        | `(T, 768)`      |
| 3    | 相加后 Dropout                      | `(B, T, 768)` | `(B, T, 768)`   |
| 4    | Transformer 块 × 12                 | `(B, T, 768)` | `(B, T, 768)`   |
| 5    | 最终 LayerNorm                      | `(B, T, 768)` | `(B, T, 768)`   |
| 6    | 输出头 `out_head`(无偏置)           | `(B, T, 768)` | `(B, T, 50257)` |

单个 Transformer 块(Pre-LayerNorm 结构):

```
x ─┬─> LayerNorm ─> 多头因果注意力 ─> Dropout ─┐
   └───────────────────(残差)──────────────────┴─> +
   ─┬─> LayerNorm ─> FeedForward(768→3072→768, GELU) ─> Dropout ─┐
    └──────────────────────(残差)────────────────────────────────┴─> +
```

多头注意力内部:`Q/K/V` 各为 `(B, 12, T, 64)`,注意力分数 `(B, 12, T, T)`,经上三角因果掩码、softmax、Dropout 后与 `V` 相乘,再拼接并经 `out_proj`(768→768,带偏置)输出。

## 3. 参数量计算(`qkv_bias=False`)

记 d = 768,V = 50257。

| 组件                          | 计算                | 参数量          |
| ----------------------------- | ------------------- | --------------- |
| 词嵌入                        | V × d = 50257 × 768 | 38,597,376      |
| 位置嵌入                      | 1024 × 768          | 786,432         |
| **每个 Transformer 块**       |                     |                 |
| 注意力 Q/K/V(无偏置)          | 3 × 768 × 768       | 1,769,472       |
| 注意力 `out_proj`             | 768 × 768 + 768     | 590,592         |
| 前馈第 1 层                   | 768 × 3072 + 3072   | 2,362,368       |
| 前馈第 2 层                   | 3072 × 768 + 768    | 2,360,064       |
| 两个 LayerNorm(scale + shift) | 2 × (2 × 768)       | 3,072           |
| 块小计                        |                     | 7,085,568       |
| 12 个块                       | 12 × 7,085,568      | 85,026,816      |
| 最终 LayerNorm                | 2 × 768             | 1,536           |
| 输出头(无偏置)                | 768 × 50257         | 38,597,376      |
| **总计**                      |                     | **163,009,536** |

### 权重共享(weight tying)

原版 GPT-2 让输出头复用词嵌入权重,此时不再单独计入输出头:

```
163,009,536 − 38,597,376 = 124,412,160  (≈ 124M)
```

这就是 "GPT-2 small 124M" 名称的由来。本书 `GPTModel` 默认**不**共享权重,因此 `sum(p.numel() for p in model.parameters())` 得到 163,009,536;第 5 章加载 OpenAI 权重时才让 `out_head.weight` 指向 `tok_emb.weight`。

### 内存占用(float32)

- 未共享:163,009,536 × 4 B ≈ 652 MB(约 621.8 MiB)
- 共享后:124,412,160 × 4 B ≈ 498 MB(约 474.6 MiB)

## 4. GPT-2 各规模配置对比

| 模型        | `emb_dim` | `n_layers` | `n_heads` | `head_dim` | 参数量(共享权重) |
| ----------- | --------- | ---------- | --------- | ---------- | ---------------- |
| gpt2-small  | 768       | 12         | 12        | 64         | 124M             |
| gpt2-medium | 1024      | 24         | 16        | 64         | 355M             |
| gpt2-large  | 1280      | 36         | 20        | 64         | 774M             |
| gpt2-xl     | 1600      | 48         | 25        | 64         | 1558M            |

四种规模共用 `vocab_size=50257`、`context_length=1024`;OpenAI 官方权重均需 `qkv_bias=True`,`drop_rate` 在推理时无影响。

## 5. 参数量粗略估算公式

忽略偏置与 LayerNorm 时,每个块约 `12 × d²`(注意力 `4d²` + 前馈 `8d²`),因此:

```
总参数 ≈ 12 · n_layers · d² + V · d + context_length · d
```

代入 gpt2-small:`12×12×768² + 50257×768 + 1024×768 ≈ 84.9M + 38.6M + 0.8M ≈ 124.3M`。
