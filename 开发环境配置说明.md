## 初始化依赖

先确认当前终端使用的是目标 Python，然后从仓库根目录安装 [requirements.txt](requirements.txt)。当前环境按账号共享依赖，使用 `--user`：

```powershell
python --version
python -m pip --version
python -m pip install --user -r requirements.txt
```

`--user` 将包安装到当前账号共享的 Python 环境，不会创建或使用项目虚拟环境。用 `python -m pip` 可以确保 pip 与 `python` 命令指向同一个解释器。

不带 `--user` 时，pip 使用当前解释器的系统级 `site-packages`，本机对应 `C:\Program Files\Python313\Lib\site-packages`，通常需要管理员写入权限。当前安装在 user-site 中；本机对不带 `--user` 的安装执行过 dry-run，所有依赖均已满足，因此不会把现有包迁移到系统目录。

安装时若提示 Python 用户级 `Scripts` 目录不在 PATH，可将该目录加入当前账号的 PATH。下面的命令会根据当前 Python 计算目录，并避免重复添加：

```powershell
$pythonScripts = python -c "import sysconfig; print(sysconfig.get_path('scripts', 'nt_user'))"
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
if (($userPath -split ";") -notcontains $pythonScripts) {
    $newUserPath = if ($userPath) { "$userPath;$pythonScripts" } else { $pythonScripts }
    [Environment]::SetEnvironmentVariable("Path", $newUserPath, "User")
}
```

PATH 更新后，重启 Windows Terminal、VS Code 或其他终端宿主，再运行 `jupyter lab`。当前机器的用户 PATH 已包含 Python 3.13 的 `Scripts` 目录。

## 核验安装

从仓库根目录执行：

```powershell
python setup\02_installing-python-libraries\python_environment_check.py
python -m pip check
jupyter-lab --version
```

环境检查脚本会逐项核对 `requirements.txt` 中适用于当前平台的包。`pip check` 应返回 `No broken requirements found.`。当前环境的依赖检查和 JupyterLab 版本检查均已通过。

## GPU 运行状态

机器安装了 NVIDIA GeForce GTX 1050 Ti（4 GB）。当前 PyTorch 是 CPU 版，`torch.backends.cuda.is_built()` 和 `torch.cuda.is_available()` 均为 `False`，因此 PyTorch 代码目前不会使用这块 GPU。若需要 CUDA 加速，应按 [PyTorch Windows 安装说明](https://pytorch.org/get-started/locally/)选择与显卡兼容的 CUDA 安装项，并在安装后检查 `torch.cuda.is_available()`。

TensorFlow 2.21 在 Windows 原生环境下不提供 GPU 支持；TensorFlow 官方说明，原生 Windows GPU 支持止于 TensorFlow 2.10，较新版本需通过 WSL2 使用 GPU。[TensorFlow 安装说明](https://www.tensorflow.org/install/pip)
